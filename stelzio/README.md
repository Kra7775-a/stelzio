# stelzio

Мультиплеерная .io-игра: сетка, краска, тьма и свет.

Красишь клетки — получаешь энергию. Энергия уходит на вспышки и рывки.
Видишь только то, что рядом с тобой: остальное на клиент честно не приходит.

## Запуск

```bash
bun install
bun run dev
```

- клиент: http://localhost:5173
- сервер: http://localhost:3000

Собрать и запустить как одно приложение:

```bash
bun run build
bun run start
```

## Управление

| Клавиша | Действие |
|---|---|
| WASD / стрелки | движение |
| Пробел | вспышка — осветить зону, потратить энергию |
| Shift | рывок |

## Стек

- **Bun** — рантайм сервера, тесты, сборка
- **Hono** + `hono/bun` — HTTP и WebSocket
- **Vite + React 19** — клиент
- **Canvas 2D + ImageData** — рендер карты и тьмы
- **TypeScript strict**, **Biome**

Без базы данных и без монорепо: комната — это несколько массивов в памяти процесса.

## Структура

```
src/
  shared/    константы, протокол, чистая логика, кодек
  server/    комната, тик-луп, видимость, раскладка по комнатам
  client/    сеть, состояние, рендер, UI

docs/        документация
scripts/     скрипты запуска
```

## Команды

```bash
bun run dev        # сервер + клиент в watch-режиме

bun run build      # сборка клиента
```
