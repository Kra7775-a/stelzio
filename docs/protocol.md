# Протокол

Обычный JSON поверх WebSocket. Поле с типом сообщения называется `t`.
Полные типы лежат в `src/shared/protocol.ts` — это один источник правды и для сервера,
и для клиента.

## Клиент → сервер

| Сообщение | Когда | Пример |
|---|---|---|
| `join` | сразу после подключения, один раз | `{ "t": "join", "name": "кот" }` |
| `input` | при нажатии клавиши движения | `{ "t": "input", "dir": "right" }` |
| `action` | при нажатии Пробела или Shift | `{ "t": "action", "kind": "flash" }` |

`input` — это просьба, а не приказ: сервер сам решит, сдвинется игрок на этом тике или нет.

## Сервер → клиент

| Сообщение | Что внутри |
|---|---|
| `welcome` | `playerId`, `slot`, `roomId`, размер карты, частота тиков |
| `full` | вся карта один раз при входе, в base64 |
| `state` | снапшот тика: `you`, видимые `players`, изменённые `cells`, `flashes`, `score` |
| `error` | текст ошибки (например, «комната заполнена») |

### Пример `state`

```json
{
  "t": "state",
  "tick": 412,
  "you": { "x": 42, "y": 17, "energy": 64, "alive": true },
  "players": [
    { "id": "…", "name": "кот", "slot": 2, "x": 45, "y": 18, "alive": true }
  ],
  "cells": [[5042, 1], [5043, 1], [5162, 2]],
  "flashes": [{ "x": 45, "y": 18, "r": 18 }],
  "score": [0, 120, 87, 0, 0]
}
```

## Как читать `cells`

`cells` — список пар `[индекс клетки, слот владельца]`.

Индекс — это «сплющенная» координата: `y * 120 + x`. Например, пара `[5042, 1]` значит
«клетка с индексом 5042 теперь принадлежит слоту 1». Слот `0` — земля стала нейтральной.

Так передаётся изменение одним числом вместо пары координат.
